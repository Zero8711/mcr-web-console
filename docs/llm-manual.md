# 콘솔 LLM 짧은 메뉴얼

슬라이드: [llm-manual.pptx](llm-manual.pptx)

시험 PC에서 COM을 붙이고, 화면을 NVIDIA에 물어보는 방법입니다.  
공개 Cloudflare Worker 와 NVIDIA API 키는 페이지에 넣지 않습니다. 중계는 사내 주소만 씁니다.

주소: [https://zero8711.github.io/mcr-web-console/](https://zero8711.github.io/mcr-web-console/)

브라우저: **Chrome 또는 Edge**. Firefox, Safari, `file://` 는 안 됩니다.

| 번호 | 칸 | 하는 일 |
|------|----|---------|
| 1 | 연결 · 이상로그 | 장비 COM을 엽니다. Baud, 콘솔 추가, 이상로그 키워드, Call Trace 샘플이 이 줄에 있습니다. |
| 2 | 명령 | ifconfig, uptime, dmesg 버튼을 누르면 선택한 콘솔로 명령이 나갑니다. |
| 3 | 공유 | 이름과 비밀번호를 넣고 [공유 시작] 합니다. 노란 줄은 링크를 어떻게 보내는지 안내입니다. |
| 4 | 시리얼 콘솔 | 장비 화면입니다. Tera Term과 같게 보면 됩니다. |
| 5 | 콘솔 LLM | 화면을 설명하거나 질문합니다. [이 칸 분석] / [묻기]. 사내 중계 또는 본인 API 키가 필요합니다. |
| 6 | 채팅 | 공유한 개발팀과 대화합니다. 로그 파일을 이 칸에 놓을 수 있습니다. |
| 7 | 명령 기록 | 누가 어떤 명령을 보냈는지 남습니다. 공유가 켜져 있을 때 쌓입니다. |

---

## 1. 페이지 열기

1. 위 공식 주소를 Chrome 또는 Edge로 엽니다.
2. LLM은 **다른 모델 쓰기** 의 중계 칸에 사내 중계 주소를 넣거나, `mcr_console.bat` 으로 엽니다.
3. 예전에 쓰던 `*.workers.dev` 공개 중계는 더 이상 쓰지 않습니다.

---

## 2. COM 연결

1. 위쪽 **[연결]** → 장비 COM을 고릅니다.
2. Tera Term이 같은 COM을 잡고 있으면 먼저 종료합니다.
3. 왼쪽 칸에 부팅 로그·프롬프트가 보이면 연결된 것입니다.

기본값: Baud **115200**, Data 8, Parity none, Stop 1, 개행 **CR**.

---

## 3. 콘솔 LLM

공개 Cloudflare Worker 주소는 **넣지 않습니다.**  
NVIDIA는 브라우저에서 바로 부를 수 없으므로, 사내 중계 또는 본인 API 키가 있어야 합니다.

| 버튼 | 언제 |
|------|------|
| **이 칸 분석** | 지금 화면에 나온 마지막 명령을 설명합니다. |
| **묻기** | 아래 칸에 질문을 쓰고 보냅니다. 예: `auto nego는 어떤 명령으로 보나요?` |

질문만 물을 때는 직전 `uptime` 같은 화면을 이유로 거절하지 않고, 확인 명령부터 답합니다.  
Call Trace / kernel panic 안내는 **채팅 칸**에만 나갑니다. 콘솔 LLM에는 안 붙습니다.

---

## 4. 개발팀에 화면 공유

COM은 시험팀 PC에만 붙습니다. 개발팀은 링크와 비밀번호만 받습니다.

1. 이름과 공유 비밀번호(영문+숫자+특수문자, 8자 이상)를 넣습니다.
2. **[공유 시작]** → 링크와 비밀번호를 같이 보냅니다.
3. 이 탭을 닫으면 공유가 끊깁니다.
4. 회사망이 P2P를 막으면 공개 TURN 없이 실패합니다. 그때는 `mcr_console.bat`을 씁니다.

---

## 바로 확인

- 주소가 `https://zero8711.github.io/mcr-web-console/` 이다.
- COM 연결 후 왼쪽 칸에 로그가 보인다.
- 공개 Worker 주소와 API 키는 비어 있다.
- 사내 중계를 넣은 뒤 **이 칸 분석** 또는 **묻기** 를 누르면 가운데 칸에 답이 온다.
