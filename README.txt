웹 시리얼 콘솔 - 사용 방법
==========================

브라우저는 Chrome 또는 Edge 만 됩니다. Firefox, Safari, file:// 로는 COM/공유가 동작하지 않습니다.

역할은 둘입니다.

  A) 원격을 여는 사람  = 시리얼 케이블이 꽂힌 PC
  B) 원격으로 접속하는 사람 = 링크만 받아 보는 사람


A) 원격을 여는 사람 (시험팀 PC)
--------------------------------
1. 연결.bat 을 실행합니다.
   cmd 창은 닫지 마세요. 이 창을 닫으면 공유가 끊깁니다.

2. Chrome(또는 Edge)이 아래 주소로 열립니다.
     http://127.0.0.1:8765/
   COM 연결은 반드시 이 주소로만 하세요.
   GitHub Pages 를 쓸 때는 아래만 엽니다.
     https://zero8711.github.io/mcr-web-console/
   Pages 에 다른 도메인을 연결하지 마세요.
   
3. [연결] 을 누르고 장비 COM 포트를 고릅니다.
   이미 Tera Term 등이 그 COM을 잡고 있으면 해제하세요.

   장비가 두 대 이상이면 [콘솔 추가] 로 칸을 만든 뒤, 그 칸을 클릭하고
   다시 [연결] 해서 다른 COM 을 엽니다. 한 화면에 최대 4대입니다.
   이상로그(에이징) 저장 파일은 칸마다 따로 지정하세요.
   공유 링크는 그대로 1개입니다. 개발팀 화면에도 같은 칸이 생깁니다.

4. 이 PC가 ipTIME 같은 공유기 뒤에 있고, 다른 자리 PC가 그 공유기 LAN이 아니면:
     - 연결.bat 이 UPnP 로 TCP 8765 포워드를 시도합니다.
       검은 창에 "UPnP: WAN ..." 이 나오면 그 주소가 공유 링크 맨 위에 들어갑니다.
     - UPnP 가 실패하면(사내/호텔에서 흔한 경우) 공유기에서 수동으로
       TCP 8765 를 이 PC로 포워드한 뒤, [공유기 사내 IP] 에
       사내망이 공유기에게 준 주소를 적습니다. (노트북 IP가 아닙니다.)
     - 출장/LTE 는 UPnP 로도 안 열립니다. 양쪽 VPN 을 쓰세요.
     - 연결.bat 창을 닫으면 UPnP 매핑 해제를 시도합니다.

5. [이름] 에 본인 이름을 적은 뒤 [공유 시작] 을 누릅니다.
   [개발팀 링크] 칸의 URL을 복사해서 접속할 사람에게 보냅니다.
   한 링크로 여러 명이 들어올 수 있습니다. (최대 20명)

6. 시험팀 Chrome 탭과 연결.bat 창을 그대로 둡니다.
   끝나면 [공유 종료] 를 누르거나 창을 닫습니다.

   다른 PC에서 페이지 자체가 안 열리면, 관리자 명령 프롬프트에서
   TCP 8765 인바운드를 허용하세요.

     netsh advfirewall firewall add rule name="WEB Serial Console 8765" dir=in action=allow protocol=TCP localport=8765


B) 원격으로 접속하는 사람 (개발팀)
----------------------------------
1. 연결.bat 을 실행하지 않습니다. COM 도 연결하지 않습니다.

2. 받은 링크를 Chrome 또는 Edge 로 엽니다.
   주소 예:  http://(시험팀주소):8765/join.html?room=...

3. [이름] 에 본인 이름을 적고 [접속] 을 누릅니다.
   상태가 초록(공유 접속됨)이 될 때까지 기다립니다.

4. 장비 명령: 보낼 콘솔 칸을 클릭한 뒤, 위쪽 명령 버튼 또는 [명령] 입력칸.
   대화: 오른쪽 채팅창. 채팅은 장비로 나가지 않습니다.

5. 페이지가 안 열리거나 접속이 안 되면:
     - 시험팀이 연결.bat 을 켠 채로 [공유 시작] 을 했는지 확인합니다.
     - 시험팀에게 공유를 다시 켠 뒤 새 링크를 받습니다.
     - 다른 자리 PC는 공유기 사내 IP + 포트포워드가 필요합니다.
       노트북 IP(192.168.50.x 등)로는 보통 열리지 않습니다.


참고
----
- COM 은 항상 시험팀 PC 에만 붙어 있습니다.
- 연결.bat 창 또는 시험팀 Chrome 탭을 닫으면 원격 접속이 모두 끊깁니다.
- 이름이 겹치면 나중에 들어온 사람은 이름2 로 표시됩니다.
- 연결.bat 검은 창의 글자는 깨짐을 막기 위해 영어입니다. 사용 방법은 이 파일을 보세요.
- GitHub Pages 공유는 사외/출장용입니다. 사내는 연결.bat 링크를 쓰세요.
  자세한 내용은 README.md 를 보세요.
